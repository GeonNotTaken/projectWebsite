UV Bit Transceiver

Finished 2026

This project involved building a digital communication system using a microcontroller to transmit and receive binary data through a custom IR-based protocol. The system was designed to encode characters into binary sequences, transmit them using infrared light, and decode the received signals back into readable text. The code handles precise bit timing, start bit detection, and idle state management to ensure reliable data transmission. The system successfully demonstrated the ability to detect and transmit full strings of text such as 'Hello World', showcasing the core functionality of IR data transfer. This project demonstrates hands-on experience with embedded systems programming, hardware-software integration, and the development of low-level communication protocols.
